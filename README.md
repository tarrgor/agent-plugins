# agent-plugins

tarrgor's plugin marketplace for Claude and Codex. Each plugin is developed in its own repository; this repository vendors tagged releases into `plugins/<name>/` and lists them in both catalogs:

- `.claude-plugin/marketplace.json` — Claude catalog
- `.agents/plugins/marketplace.json` — Codex catalog (Codex accepts only plugins stored inside the marketplace repository)

Both catalogs are generated by `scripts/sync.py`; don't edit them or `plugins/` by hand.

| Plugin | Source |
|---|---|
| `sdd-workflow` | [tarrgor/sdd-workflow-skills](https://github.com/tarrgor/sdd-workflow-skills) |

## Install

**Claude (claude.ai, cloud and terminal sessions):** in claude.ai open **Customize → Plugins**, add the marketplace `tarrgor/agent-plugins`, and install plugins from it. Locally only:

```bash
claude plugin marketplace add tarrgor/agent-plugins
```

```bash
claude plugin install sdd-workflow@agent-plugins
```

**Codex:**

```bash
codex plugin marketplace add /absolute/path/to/agent-plugins
```

```bash
codex plugin add sdd-workflow@agent-plugins
```

Plugins are pinned to release tags and carry the tag's version, so clients update only when a new release is synced.

## Publish a new release

Tag the release in the plugin's own repository, then either run the **Sync plugin** workflow (Actions → Sync plugin, with plugin name and tag) or locally:

```bash
python scripts/sync.py --plugin sdd-workflow --ref v1.2.0
```

and commit the result.

## Add a plugin

The plugin repository needs `.claude-plugin/plugin.json` and/or `.codex-plugin/plugin.json` at its root and a semver release tag. Add an entry to `sources.json` (`name` must equal the manifests' `name`; `include` lists the files to vendor), then run `python scripts/sync.py` and commit.

## Checks

```bash
python scripts/validate.py
```

```bash
python scripts/sync.py --check
```

CI runs both on every push and pull request.
